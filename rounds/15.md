# Round 15 — Export/Import, Global Search & Production Polish

## Current Product State
Fourteen rounds in. The product has a complete core workflow (benchmarks → runs → evolution), marketplace with snapshot versioning and moderation, teams, notification center, API v1 with token abilities, admin panel, and full i18n. This round added data portability (JSON export/import), global search, and production polish.

## Selected Goals
1. Export benchmarks as downloadable JSON.
2. Import benchmarks from uploaded JSON exports.
3. Global search across prompts/benchmarks visible to the user.
4. Favicon + production polish.

## Implementation Summary
- **Export**: `GET /benchmarks/{id}/export` streams a JSON payload with all cases + criteria; owner-only; Content-Disposition triggers download with a slugged filename.
- **Import**: `POST /benchmarks/import` accepts a JSON file upload, validates required fields via `ImportBenchmark` action, creates benchmark + cases + criteria in a transaction. Invalid JSON or missing fields redirect with errors.
- **Search**: `SearchController` queries prompts + benchmarks by name/description using `scopeVisibleTo` (team-aware). Results rendered on a dedicated `/search?q=` page grouped by type. Authenticated route.
- **Polish**: SVG favicon matching the brand tile (violet rounded square with white "O"), linked in the root blade template.
