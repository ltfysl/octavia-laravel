# Round 12 — Update-Available for Marketplace Installs

## Current Product State
Round 11 froze snapshots at publish. But buyers had no way to know a listing they installed had moved ahead — the marketplace card always showed "Install" regardless.

## Selected Goals
1. Track the installed version per user per item.
2. Show an "Update to vN available" badge and relabel the install button to "Update" when the listing version moves ahead of the installed one. Reinstalling (from the frozen snapshot) updates the tracked version.

## Implementation Summary
- **Schema**: `marketplace_installs` — item FK (cascade), user FK (cascade), version, unique `(item, user)`.
- **Install**: upserts the install record with the current item version inside the same transaction as the content copy.
- **Index**: shares `installed_version` per item (plucked per user); the card shows an amber "Update to vN available" badge and relabels the button to "Update" when `installed_version < version`.
- **Semantics**: reinstalling re-copies the frozen snapshot content as a fresh private copy — consistent with the snapshot-versioning model (installed items are independent copies, not live links).
