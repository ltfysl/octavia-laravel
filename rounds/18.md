# Round 18 — Reporter Resolution Mail & Team Run Visibility

## Current Product State
Seventeen rounds in. All core workflows complete and tested (108 tests / 378 assertions). This round closed two gaps: the report-resolution loop only notified via database channel, and runs were invisible to team mates even though prompts/benchmarks were team-aware.

## Selected Goals
1. Notify reporters via email when their report is resolved (respecting per-user mail opt-out).
2. Run-level team scoping — team mates can view shared runs; index shows team runs with owner attribution.

## Implementation Summary
- **MarketplaceReportResolvedNotification**: now queueable, adds `mail` channel gated on `notify_run_completed_mail` preference (reuses the established opt-out pattern), localized EN/DE via `notifications.report_resolved.*`.
- **RunPolicy::view**: owner OR team mate (`teamMateIds()`), mirroring Prompt/Benchmark visibility.
- **Run::scopeVisibleTo**: team-aware scope for queries.
- **RunController::index**: uses `visibleTo()`, eager-loads owner, exposes `owner` prop.
- **runs/Index.vue**: shows owner name next to badge when present.
