# Round 17 — Prompt Export/Import, Run Search & Error Page Tests

## Current Product State
Sixteen rounds in. The product is mature across all core workflows. This round filled remaining gaps: prompt JSON export/import (mirroring benchmarks), run inclusion in global search, and error page test coverage.

## Selected Goals
1. Prompt JSON export/import — mirror the benchmark pattern for data portability.
2. Extend global search to include runs (name matching, owner-scoped).
3. Error page test coverage for branded 404/403 rendering.

## Implementation Summary
- **Prompt export**: `GET /prompts/{id}/export` streams all versions + metadata as JSON (owner-only).
- **Prompt import**: `POST /prompts/import` accepts JSON file, creates prompt + all versions in a transaction, sets latest version as current.
- **Search runs**: SearchController now queries runs by name for the authenticated user; SearchResults page renders a Runs section.
- **Error page tests**: 404 renders branded page for guests; 403 renders for users without admin access.
